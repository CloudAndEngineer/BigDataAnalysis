빅데이터분석개론 3차시 필기

합성곱 연산(CNN) 진행 방법

Y(i, j) = Σ(u: 0 ~ m - 1) Σ(v: 0 ~ n - 1) X(i + u, j + v) K(u, v)

의미
축소된 이미지의 [i, j] 칸에서 합성곱의 결과는
입력 이미지의 [i, j] 칸에서 시작하는 [m, n] 크기의 커널을 올려놓고
커널의 [u, v] 칸과 해당 위치의 입력 이미지 칸의 숫자를 곱한 것이다.

ex.
X: [[0, 1, 2], [3, 4, 5], [6, 7, 8]] K: [[0, 1], [2, 3]]

Output: [
	[0*0 + 1*1 + 3*2 + 4*3, 1*0 + 2*1 + 4*2 + 5*3],
	[3*0 + 4*1 + 6*2 + 7*3, 4*0 + 5*1 + 7*2 + 8*3]
]
= [[19, 25], [37, 43]]

스트라이드: 커널이 이동하는 간격

패딩: 입력의 가장자리에 0을 채워넣음
원본 이미지로만 계산을 진행하면 가장자리의 값은 상대적으로 적게 참조되고, 출력 이미지의 크기가 점점 작아짐

출력 크기
Stride가 클수록, Kernel이 클수록 출력의 크기는 작아진다.
출력의 크기는 Stride의 크기에 반비례한다.
커널이 이동할 수 있는 거리는 입력 이미지의 (가로/세로) 길이 - 커널의 (가로/세로) 길이이다.
시작 지점까지 포함해야 하므로 출력의 크기는 Stride에 상관없이 1 늘어난다.
Padding이 있다면, 커널의 이동 거리는 (2 * Padding 크기)만큼 늘어난다.
따라서
출력의 (가로/세로) 크기는
Floor{(입력 이미지의 (가로/세로) 길이 - 커널 크기 + (2 * 패딩 크기)) / 스트라이드} + 1

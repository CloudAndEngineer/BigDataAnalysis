파이썬 모델 실행 과정

__init()__: 모델 구조 초기화
__call(x)__: 객체를 함수처럼 호출함
forward(x): 모델의 계산 방법을 정의
Linear Layer: 선형 변환
Output

회귀 문제(연속적인 데이터 추출)의 손실 함수
모델의 출력이 연속적인 실수값이기 때문에 
MSE(Mean Squared Error): 예측값을 기반으로 한 실제 값의 분산이라고 볼 수 있음
-> (실제값 - 예측값)의 2차 적률

분류 문제(이산적인 데이터 추출)의 손실 함수

소프트맥스 함수: e^yi / (e^y1 + e^y2 + ... + e^yn)
지수를 사용하는 이유: 확률이 높은 것을 더 증폭시키기 위함

교차 엔트로피 손실(Cross-Entrophy Loss) 함수: -y @ f(x)
y= 0, 1로 표현된 정답 벡터
f(x)= 소프트맥스 함수를 통과한 확률 값 벡터
높은 확률을 부여할수록 값이 감소함

소프트맥스로 확률 만들기 -> 교차 엔트로피 손실 함수로 벌점을 매김
실제 정답에 관한 텐서를 만들 때 정답은 1, 오답은 0으로 표시
소프트맥스 함수의 결과에 각각 로그(ln) 처리

ex. 실제 정답이 [0, 1, 0] 이고 원본 점수가 [2.0, 1.0, 0.1]인 경우
소프트맥스를 통과시켜 텐서 [0.65, 0.24, 0.11]를 구한다.
- [0, 1, 0] @ [ln(0.65), ln(0.24), ln(0.11)] = -ln(0.24) = 1.427 이므로
교차 엔트로피 손실은 1.427이다.

optimizer.zero_grad(): Gradient 초기화
model(x): forward propagation
criterion(): loss 계산
loss.backward(): Gradient 계산
optimizer.stop(): weight 업데이트
